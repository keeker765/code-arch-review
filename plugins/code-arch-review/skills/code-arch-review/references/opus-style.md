## 先划三条边界,否则这页会把人带到反面

**① 这不是"某某没达标"。** 被对照的四份代码 `check.py` 全部 0 违规。本页写的是**闸量不到
的那一层** —— 闸能数出"每个 if 上面有没有注释",数不出"这句注释说了什么"。

**② 长度不是指标。** 被引为范本的 `opus2_layer3_calib_full.py` 模块 docstring 只有 12 行。
判据是**回答了下面哪几问**,不是写了多少字。

**③ 🔴🔴 不要为本页开一轮全量重写。** 顺序仍然是
`能跑的代码 → 主任务闭环 → 统一补注释`(见 SKILL.md)。
**新写的按这个写;存量在下次动到它时顺手补。** 专门开一轮重注释,正是用户点名要避免的
过度工程 —— 而且它产出的是最没有价值的那种注释(见下面的"两条反噬")。

## 🔴🔴 两条反噬 —— 先读这个,再读七条

这两条由 hour_opus1 与 hour_opus2 在本页定稿当天主动提出,**它们比七条本身更重要**,

## 七条

### 1. docstring 要回答「为什么是这个设计,不是另一个」,并点名被否决的替代方案

范本 `src/evaluation/backtest/research/hourly_gate/layer1.py:1-30`:用三段解释「两道闸为什么
不合成一个数」——

> 两道闸分开而不是合成一个总分,是因为它们的**失败含义不同**:成本闸不过 = 这条腿亏钱,
> 没有下游;效应闸不过 = 它赚的钱与同换手的随机信号无法区分,还可能是别的 H 的问题。
> **合成一个数之后这两种失败在结果表上同形,而它们的处置相反。**

并**点名**三种被否决的归一写法(除以 `|floor_bp|`、减去 `floor_bp`、比值 `gross/turn`)
以及它们各自退化成什么。

⇒ 反面形态:「本模块只产门与动作元数据,真正乘权重由 overlap 层负责」—— 这是**分工声明**,
不是**设计论证**。读者无法判断这是口味还是正确性。
⚠ 受第一条反噬约束:**没真推过替代方案就不要写这一节。**

### 2. 每条禁令后面跟【具体后果】,不是"会不准"

范本:「⚠ 主尺一律 taker 4.174bp;`g/t ∈ [1.926, 4.174]` 是**已知假阳性带**,
用 maker 1.926 当判据线**会放行一整批亏钱的因子**。」

⇒ 反面形态:「市场级标量禁止退化成整本书同开同关」「不允许隐式广播到错误时间轴或币种轴」——
禁令清楚,**后果没写**。而后果那半句才是这行 `raise` 真正防住的东西:广播错了会**静默**产出
一本形状正确、对齐错误的书。

### 3. 能力边界成对写:它保证什么 **+** 它不保证什么

范本(`opus2_layer3_calib_full.py::mem_guard`,临时脚本,原文摘录):

> 判据是 `VmHWM` 不是 `VmRSS`:后者是采样值,两个步进点之间的瞬时峰会漏掉
> ⇒「软闸没报错」推不出「全过程 RSS ≤ 预算」。`VmHWM` 单调递增,语义正是「曾经越过预算」。
> ⚠ 它保证越界不被瞒过,但抓到的时刻是**下一个**步进点 —— **能归因,不能阻止**越界发生。
> ⚠ 按进程统计:线程池算得到,fork 的子进程算不到。

来源仓库里另一个范本 `src/evaluation/backtest/intraday/lab/pathstop.py:1-7` 末句:
「后者是 OHLC 分辨率下的模拟,**不是已知的真实成交价或秒级触发时刻**」。

⚠ 受第二条反噬约束:**写之前先真的想一遍"它抓不到什么"**,想不出就别写这一节。

### 4. 非显然的约定带【归属 + 日期】`(谁 YYYY-MM-DD)`

范本:「主尺一律 taker 4.174bp(**用户 2026-08-23**)」;
「🔴 RLIMIT_DATA 不当主闸(**archer 2026-09-17 撤销原纪律,一晚四次假失败**)」。

理由:三个月后要改它的人得知道**去问谁、当时发生了什么**。
**没有归属的规矩只有两种命运** —— 不敢动,或者整条删掉。

### 5. 踩过的坑当场写,并写明【为什么会踩】

范本 `src/evaluation/backtest/research/hourly_gate/layer0.py` 的产物节:

> `scan_layer0.csv` —— **每算完一个因子立刻 append 一行**(本包在同一位置栽过两次:
> 跑到 16/50 挂掉、已算的 16 个结果全丢),启动时按 `meta.json` 的 `code_fp` 跳过已完成项。

范本(opus2):「它限的是 **虚拟数据段 VmData**,而预算口径是 RSS ⇒ **闸限的量和预算的量
不是同一个**。」—— 价值全在最后半句。写成「这里有个 bug 已修」,下一个人还会踩。

⚠ 这是**唯一不可延后**的注释用途(见 SKILL.md 的顺序规定)。

### 6. 标记分级统一,不要全部同权

```
🔴  违反会产生【错误结果】,而且往往【不报错】
⚠   已知边界 / 未测 / 有前提
⭐  可迁移到别处的通则
⬜  待复现、待定,不是结论
```

不分级 = 所有句子同权,读者只能逐条自己掂轻重,而**最该被看见的那条没有任何标记把它顶起来**。

### 7. 产物的【绝对路径】写进 docstring

范本 `layer1.py` 末段:

> 产物:`layer1_<tag>.csv`(逐格一行)+ `pool_identity.json`(先写)+ `pool_counts.json`。
> 结果头写产物绝对路径与工作量指纹 —— **一个没有产物路径的数字,后来的人无法验证,
> 而它读起来和一个验证过的数完全一样。**
