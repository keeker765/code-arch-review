# opus 写法 —— 闸量不到的那一层

> 🔴 用户 2026-09-17 定:对照后「让别的都学 opus 的写法」。七条,**每条都可逐条对照**。
>
> 本页点到的文件名都是**来源仓库**里的,只作写法参照,换项目时路径不存在。

## 三条边界

1. **不是「某某没达标」**:被对照的四份代码 `check.py` 全部 0 违规。本页是闸量不到的
   那一层 —— 闸能数「每个 if 上面有没有注释」,数不出「这句注释说了什么」。
2. **长度不是指标**:范本模块 docstring 只有 12 行。判据是回答了哪几问,不是字数。
3. 🔴 **不要为本页开一轮全量重写。** 顺序仍是 `能跑的代码 → 主任务闭环 → 统一补注释`。
   新写的按这个写;存量下次动到时顺手补。

## 🔴 两条反噬(比七条本身更重要)

**格式可以被填空,位置不能被假装到达。** 照着格式写「被否决的替代方案」而没真推过,
会写出一份看起来更权威的错 docstring;照抄「能力边界成对写」而不想「它抓不到什么」,
产出的是一句好看的空话。

⇒ 通则:**每一条的价值在于它强制你到达某个位置,不在于留下的形状。**
到不了那个位置就**别写那一条** —— 空着比一句权威的空话好。

## 七条

1. **docstring 回答「为什么是这个设计,不是另一个」,点名被否决的替代方案。**
   范本用三段解释两道闸为什么不合成一个数:失败含义不同,合成后结果表上同形、处置却相反。
   ⇒ 反面形态是**分工声明**(「本模块只产元数据,乘权重由下游负责」)—— 读者分不清
   这是口味还是正确性。⚠ 没真推过替代方案就不要写。

2. **每条禁令后面跟【具体后果】,不是「会不准」。**
   范本:「用 maker 1.926 当判据线**会放行一整批亏钱的因子**。」
   ⇒ 禁令清楚、后果没写,等于没写完;后果那半句才是 `raise` 真正防住的东西。

3. **能力边界成对写:保证什么 + 不保证什么。**
   范本:「`VmHWM` 单调递增,语义是『曾经越过预算』;但抓到的时刻是**下一个**步进点 ——
   **能归因,不能阻止**,线程池算得到,fork 的子进程算不到。」
   ⚠ 写之前先真的想一遍「它抓不到什么」,想不出就别写这一节。

4. **非显然的约定带【归属 + 日期】。**
   例:「主尺一律 taker 4.174bp(**用户 2026-08-23**)」。
   三个月后要改的人得知道去问谁、当时发生了什么。没有归属的规矩只有两种命运:
   不敢动,或者整条删掉。

5. **踩过的坑当场写,并写明【为什么会踩】。**
   范本:「每算完一个因子立刻 append 一行(本包栽过两次:跑到 16/50 挂掉、已算的全丢)。」
   写成「这里有个 bug 已修」,下一个人还会踩。这是**唯一不可延后**的注释用途。

6. **标记分级统一,不要全部同权。**
   ```
   🔴  违反会产生【错误结果】,而且往往【不报错】
   ⚠   已知边界 / 未测 / 有前提
   ⭐  可迁移到别处的通则
   ⬜  待复现、待定,不是结论
   ```
   不分级 = 最该被看见的那条没有任何标记把它顶起来。

7. **产物的【绝对路径】写进 docstring。**
   产物名 + 先写哪个 + 结果头写绝对路径与工作量指纹。
   一个没有产物路径的数字,后来的人无法验证,而它读起来和验证过的数完全一样。

## 标点

标点**随仓库**:按目标项目既有习惯,同一个文件里别混用。发现项目内不一致时,
下次动到那些文件时顺手统一,不专门开一轮。

## 对照表 —— 自检时逐行问

| # | 问自己 | 到不了这个位置时 |
|---|---|---|
| 1 | 我真的推过被否决的那个方案吗? | 空着,别写 |
| 2 | 违反这条禁令会具体发生什么? | 说不出就说明禁令本身可疑 |
| 3 | 这个东西抓不到什么? | 想不出就别写「保证」 |
| 4 | 这条约定是谁定的、哪天? | 查 git blame 或问 |
| 5 | 为什么会踩这个坑? | 写不出 = 根因没找到,别急着修 |
| 6 | 这句该是 🔴 还是 ⚠? | 分不清说明后果没想清 |
| 7 | 产物落在哪个绝对路径? | 没有产物 ⇒ 这个数不该被引用 |
